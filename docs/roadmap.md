# Roadmap beyond the local MVP

Delivered: deterministic checks, persistent SQLite records, authenticated operator/reviewer workflows, mock ERP, audit view, local dashboard, four Jupyter notebooks, synthetic ML benchmark and CI tests.

Not delivered: PDF OCR and extraction, real LangGraph/LLM orchestration, RAG, real ERP integration, robust multi-user identity, production Postgres migrations, distributed workers, ML use in the live workflow, external deployment, system security certification. These are separate product initiatives, not implied features of this release.

Recommended next milestone: build a synthetic PDF invoice ingestion pipeline with parser confidence metrics and an evaluation set, while ensuring monetary checks remain deterministic and human-auditable.
